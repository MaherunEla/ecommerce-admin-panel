# E-Commerce Admin Panel

## Project Overview

This project is an E-Commerce Admin Panel developed as part of the backend internship task. It follows a modular backend architecture using Express.js, Prisma ORM, and PostgreSQL, with a Next.js frontend.

---

## Tech Stack

### Backend

- Node.js
- Express.js
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT Authentication
- Cookie-based Authentication

### Frontend

- Next.js 16 (App Router)
- React
- TypeScript
- Redux Toolkit
- Axios
- Tailwind CSS
- shadcn/ui

---

## Backend

```bash
npm install

```

```
http://localhost:5000
```

---

## Frontend

```bash
npm install
npm run dev
```

Frontend runs on:

```
http://localhost:3000
```
